## 关于这个博客

这里是我的「数字后花园」。不追热点、不蹭算法，只认真记录我想留下的东西：

- **技术折腾笔记**：建站、编程、工具与踩坑记录；
- **ACG 日常**：番剧、游戏、音乐和碎碎念；
- **生活随想**：旅行、摄影，以及微小却值得纪念的瞬间。

程序基于 [Hexo](https://hexo.io/) 与 [Butterfly](https://github.com/jerryc127/hexo-theme-butterfly) 主题搭建，托管在 GitHub Pages 上。
